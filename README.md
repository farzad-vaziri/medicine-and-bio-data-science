# Medicine and bio data science

A collection page of live dashboards in medical and biological data science: cancer genomics, single-cell biology, clinical trials, drug safety, patient pathways and readmission risk.

**Live page:** https://farzad-vaziri.github.io/medicine-and-bio-data-science/

One static page (`index.html`) served by GitHub Pages from `main`. Images are in `assets/previews/`, and fonts (IBM Plex Sans and IBM Plex Mono, SIL Open Font License) are self-hosted in `assets/fonts/`. There is no build step.

Every dashboard on the page links to its live Streamlit app.
